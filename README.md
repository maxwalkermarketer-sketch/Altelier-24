ATELIER RUN — Performance Footwear Landing Page

A fictional e-commerce landing page concept for a premium running footwear brand, designed around minimalism, product presentation, and a clean shopping experience.

Overview

ATELIER RUN explores how an understated, Apple-inspired visual direction can work for a performance running brand. The interface combines generous whitespace, restrained typography, neutral surfaces, and product-focused layouts.

This is a portfolio concept created to demonstrate frontend development, visual design, and e-commerce interface skills.

Features

- Responsive layout for desktop and mobile screens
- Minimal navigation with a mobile menu
- Hero section with a clear call to action
- Three fictional running-shoe product concepts
- Product cards with illustrative prices
- Interactive shopping bag with add and remove actions
- Automatic subtotal calculation
- Smooth transitions and scroll-based reveal effects
- Accessible labels and reduced-motion support

Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts — Inter
- Unsplash-hosted photography

No frontend frameworks or paid UI libraries are required.

Getting Started

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Explore the landing page and test the shopping bag interactions.

An internet connection is needed to load the externally hosted fonts and images.

Design Direction

The interface follows a restrained visual system:

- Warm white backgrounds
- Near-black typography
- Subtle borders and neutral product surfaces
- Generous spacing and clear visual hierarchy
- Smooth, controlled interactions
- Responsive layouts designed for smaller screens

Limitations

This is a frontend demonstration, not a functioning online store. Product names, prices, and descriptions are fictional. The shopping bag operates in the browser only; there is no backend, inventory management, checkout, or payment processing.
